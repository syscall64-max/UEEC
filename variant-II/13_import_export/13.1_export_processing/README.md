# Stage 13.1 — Export table processing
Based on Stage 12.6 final loader and original 08_export/ueec_export.h. Wire convention follows the original generator/converter: low five bits for resident section index, excluding HEADER; flat length in upper eleven bits. Metadata byte order is independent of target architecture.
`make test` runs all 12 target environments; `make sanitize` runs x86-64 with ASan/UBSan. `make x86_64` runs only host tests. CLI: `build/x86_64/export auto FILE name a` or `... ordinal 3`. Exit codes: 0 found, 3 missing, 1 invalid image/table, 2 usage/I/O.
Each architecture: 54 common fixture variants, 864 lookup cases (648 found + 216 missing), 378 malformed table cases. Four loading modes. Lookup validates the entire table and scans linearly; binary search optimization is not implemented. Export sections are nonresident; relocation sections remain supported by the inherited loader but combined relocation/export regression has not been run here. The CODE section contains an opaque byte marker, not executable payload; no execution or function ABI is tested in this stage. Data lookup reads one byte to verify resolved address. Duplicate matching symbols across multiple tables are rejected; global cross-table uniqueness is not checked. Flat name blob may contain unused bytes. Only one export section per node is tested. No import or export conversion yet. No changes to the original export header. Existing loader source retained with changes for export section filtering and optional relocation.
