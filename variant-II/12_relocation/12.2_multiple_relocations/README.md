# Stage 12.2 — FLAT multiple relocations
Run `make test` and `make sanitize` from 12_relocation. Requires the same 12 cross toolchains and QEMU runners as stage 12.1.
Four couple16 records, eight native-width ABS pointers per selected node: three to CONSTANT_DATA, two to INIT_DATA, two to UNINIT_DATA, one to CODE. All eight checked against mapped addresses; the existing native payload dereferences the first. Metadata endian and pointer endian are independent. Addends are unsigned section-relative offsets (as in the original loader); negative/outside-source offsets are rejected. Only INIT_DATA destinations, one trailing FLAT section, couple16, no instruction patches. Overlapping writes rejected. Invalid images are discarded without executing.
72 positive and 18 rejection cases per architecture. Positive cases repeat three load cycles with two native calls each. Negative cases mutate selected-node metadata or addend for both file byte orders; auto mode only. JSON report retains rejection counts separately. Local validation on x86-64 used placeholder bytes in unselected nodes; no placeholders or build outputs are distributed.
