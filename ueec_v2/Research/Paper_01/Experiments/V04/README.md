# V04 — C Import/Export Performance
Linux x86-64, Python 3 and GCC-compatible cc. Run `./run.sh 20` (default), or `./run.sh 100` for more samples. `./run.sh 1` is a smoke test, not robust timing evidence. Original load.c, resolve.c, ueec.h extracted byte-for-byte from the supplied research/ueec-v2-organization ZIP, stage 13.6. A generated include changes only the resolver CLI main identifier to avoid collision with the harness. No resolver algorithms changed. SHA-256 verified before/after.

324 configurations: 6 symbol counts (1,16,64,256,1024,4096), 3 import/export widths (matched), 3 export designs, 2 metadata endiannesses (matched between modules), 3 allocation modes. Outer section headers always SH32, names fixed 6 ASCII bytes. One library exports distinct byte offsets in a constant-data section; app slots are 8-byte aligned INIT_DATA. Code is a dummy RET and is not executed. Actual modules are loaded before timing. Every lookup verifies expected found/section/offset, and every bind verifies all pointer slots. Input file hashes verified across runs. Five lookup warmups per query; no separate binding warmup. Slots cleared outside timer before each bind. CLOCK_MONOTONIC_RAW, ns. First/middle/last/missing lookup calls original table(), which scans and validates the whole export table. Binding calls original bind_imports(), includes lookup, allocations, duplicate-slot checks, patching, pointer readback and diagnostic printf (stdout redirected to /dev/null, not eliminated). No relocation or dependency graph in these fixtures. No CPU pinning/frequency control, cold cache, or ELF comparison. Binding may grow quadratically and large repeats can be slow. No native external function execution measured here (V01 covers functional tests).

Output samples.csv and summary.csv (min, median, mean, nearest-rank P95, max). Each config yields 5 * repeat count timing observations. Config count does not increase with repetitions. Packaged CSVs are local smoke-test results, one sample each; do not infer stable medians from these. User should preserve outputs before rerunning as CSVs are overwritten.
