# V02 — Memory protection
Linux x86-64, GCC or compatible cc, Python 3. Run ./run.sh.
Original 12.6 load.c and ueec.h are unchanged, included by probe.c with main renamed. The independent harness calls the original parser and image builder. Six fixtures (three SH widths, two metadata byte orders), three forced modes. Each fixture contains a valid ABS64 relocation into BSS; relocation metadata is temporary, not resident. Each of five resident sections is checked via /proc/self/maps, actual read and write in separate forked children; CODE and three data sections additionally receive execution probes using x86 RET. Writable data gets RET written in the child; constant data already contains RET. HEADER execution is not attempted (its bytes are not a valid controlled instruction sequence); its NX status is checked via maps only. A denied probe must terminate by SIGSEGV or SIGBUS. Core dumps disabled. Input bytes and source hashes checked. Counts: 18 configurations, 90 section groups, 342 individual checks (90 permission, 90 read, 90 write, 72 execute). No claim about other CPU targets or hardware NX enforcement beyond this environment. No sanitizer run. Initial fixture generator needed correction to satisfy original loader's mandatory relocation requirement and resident index convention; loader unchanged.
