# E02.6 — combined CODE, CONSTANT_DATA, INIT_DATA and UNINIT_DATA
Run `./run.sh` on Linux x86-64 with GNU binutils, C compiler and Python 3. This reuses the E02.5 experimental v1 loader, with a narrow bridge for three FLAT ABS64 relocations. Original source and cumulative patch are retained. This is not the unmodified v2 loader. Relocation remains resident.
The 134-byte machine-code sequence checks every UNINIT_DATA byte for zero, sums 16 constant and 16 initialized bytes, increments and checks the first initialized byte, writes sum+5 to UNINIT_DATA and checks it and the final byte. Base exit 57; control exit 58 (one constant byte changed). Addresses and size immediate are patched per fixture. Physical files deliberately contain A5 in unused UNINIT_DATA bytes. NOBITS is experimental, enabled externally by UEEC_EXPERIMENT_NOBITS=1, not self-describing or standardized.
4 sizes x 2 input cases x (2 ELF + 3 widths x 3 modes x 2 layouts) = 160 positive runs, 64 files. UEEC runtime header address array and mode/region count are checked. ELF compact uses RWX; split uses RX/R/RW with page-aligned offsets 4096 and 8192, not claimed to be minimum. No independent protection probes, no invalid-file suite, no timings. Logical file size excludes loader. results.csv records base sizes (control has identical sizes); execution.csv and test.log record both cases. Trusted generated fixtures only. Documentation and publication deferred.
