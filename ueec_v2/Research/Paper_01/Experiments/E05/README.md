# UEEC Paper 01 — E05: Endianness
Run `./run.sh` on Linux x86-64 with Python 3 and GCC/Clang. The E04 experimental first-generation loader was modified to decode fixture-specific FLAT relocation metadata using the container byte order and to reject non-native node payload byte order. The previous source and experiment.patch are retained. x86-64 code and 16-byte constant data remain byte-identical across the two container byte orders. Native code compares a 32-bit little-endian constant with 0x12345678 and exits 42 for equality or 43 otherwise. Both cases run for three header widths, two container byte orders and three loading modes (36 executions). Two malformed flag cases per width/order/mode give 36 expected rejections, for 72 checks total. Wrong payload flag rejection is specific to this native x86-64 experiment; it does not establish cross-architecture execution. This is not a general relocation decoder or a full endianness converter. No original project files or official specification changed. Runtime header address checks and region counts are inherited from E04. No performance measurements. Generated CSV and logs reflect the last run.
