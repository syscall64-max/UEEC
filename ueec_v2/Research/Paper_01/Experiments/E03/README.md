# E03 — physical section sharing
Linux x86-64, Python 3 and C compiler. Run ./run.sh. Six node counts (2,4,8,16,32,64), four constant-data sizes (16,256,4096,32768), three section header widths and three load modes. Each node reads both endpoints of the constant section and adds its unique index (expected exit 40+index). All nodes are executed. Shared and duplicated UEEC variants both share the identical relocation section; only constant-data sharing differs. ELF baseline is a set of independent compact ELF64 executables with a single RX segment each, not a multiarch container. Sizes sum logical file lengths, not filesystem allocation, compression or loader size. The loader is the E02.7 experimental v1 derivative with the constant-data length restriction relaxed. Its relocation bridge is fixture-specific, not a general relocation engine. No interprocess memory sharing or performance claim. No repository modification. results.csv contains size measurements; execution.csv records every execution. test.log contains grouped totals. SHA256SUMS covers source and generated results/fixtures before rerunning.
