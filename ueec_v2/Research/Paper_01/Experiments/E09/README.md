# E09 — Import and Symbol Resolution
Run ./run.sh on Linux x86-64 with Python 3; no third-party modules. Reference implementation, not the production C loader.
Import encoding follows bind_imports() in UEEC repository commit d41a9eab979403184e88499745b9e9acaa89b5fb, path ueec_v2/Linux/CPU/Import_Export/13.6_full_integration/resolve.c. The draft Core/Headers/ueec_import.h was also inspected. Import design 0 uses u16 format/design, width-sized library count, u16 length-prefixed library name, width-sized entry count, u8 kind, width-sized resident section and offset, then width-sized ordinal or u16 length-prefixed symbol name. Metadata endian is explicit. Export reference encoder/decoder reused from E08. The registry is a Python dictionary, not the C resolver; destination is a bytearray representing one writable resident section. Bindings are staged before writes. Native calls use actual resolved pointers into an anonymous mmap changed from RW to RX. All generated functions return a distinct integer. No full UEEC files, loader modes, dependency graph, independent library endian or export/import widths, external data ABI, relocation overlap or timing are tested. One library per positive case. Negative tests cover missing library/symbol, duplicate, unaligned, out-of-range and wrong-section slots, truncated and appended bytes. No claim of exhaustive malformed-input validation. Counts are repeated checks, not independent programs.
ELF64 estimate = 24*N RELA + 24*(N+1) Dynsym + 1+sum(name length+1) Dynstr. Excludes dynamic/hash/version tables, library name, GOT/PLT and alignment. PE64 estimate = two 20-byte descriptors + two 8-byte thunk arrays with terminators + NUL-terminated library name + aligned hint/name records. Excludes other directories and alignment. These are selected structures, not equivalent complete binaries, nor actual ELF/PE loader tests. Ordinal imports are not directly equivalent to named imports. Export bytes are not included in UEEC import sizes. This experiment does not modify the official repository.
