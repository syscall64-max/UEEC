# E08 — export section structural and functional experiment
Run `./run.sh` on Linux x86-64 with Python 3. No external Python packages.
Wire layouts based on the unmodified header from UEEC-main.zip, 08_export/ueec_export.h. The test uses a new Python reference encoder/decoder (not the production UEEC loader). Metadata uses explicit byte order and low-bit section encoding. The tests decode complete export sections, check all keys using a Python dictionary and check a missing key. Selected first/middle/last functions execute native x86-64 `mov eax,imm32; ret` code via ctypes and a temporary RWX anonymous mapping. This does not test full UEEC containers, three loader modes, production binary search performance, or memory protection. Malformed tests only cover truncation and appended bytes. Named layouts round-trip across all three widths; ordinal has no lossless named conversion. Export widths are independent of container section header widths. ELF comparison is a calculated Elf64_Sym table (including null symbol) plus string table (including initial NUL), no hash/version/dynamic metadata. PE comparison is a calculated 40-byte export directory plus 4-byte address, 4-byte name pointer and 2-byte ordinal entries per symbol plus NUL-terminated names; excludes DLL name and padding. Named comparisons apply only to named UEEC designs. No actual ELF/PE binary or loader tested. Counts include repeated checks across endian, width and name patterns. No performance claims.
