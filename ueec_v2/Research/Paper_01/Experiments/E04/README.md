# UEEC Paper 01 — E04: Section header widths
Run `./run.sh` on Linux x86-64 with Python 3 and GCC/Clang. The loader is copied unchanged from E03 (experimental first-generation loader, original and patch retained). The restricted converter handles one little-endian node with HEADER/CODE/CONSTANT_DATA/RELOCATION, physical layout only; not a universal UEEC converter. It preserves payloads and header padding, recalculates HEADER lengths, and rejects unrepresentable values. The field checks use isolated serialized records, not complete multi-gigabyte files. The 426 loader checks include 372 successful exit=40 executions and 54 expected runtime-header-width rejections on 4096-byte pages. Counts include identity conversions and repeated execution of equivalent output. Page size affects rejection counts. The code checks the first and last logical data bytes; the converter separately checks byte-exact payload and round-trip equality. No changes to the official specification or GitHub.
