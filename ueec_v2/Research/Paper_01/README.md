# UEEC — Paper 01 research materials

Publication staging area, based on the second-generation research snapshot `d41a9eab979403184e88499745b9e9acaa89b5fb`.

Scope: experimental evaluation of the UEEC executable format for Linux CPU targets, with structural comparisons to ELF, PE and Mach-O. Reports are research drafts, not a peer-reviewed paper. The existing implementation and specifications remain unchanged.

Planned material: E01–E12 (including supplementary E04.2), V01–V05 (including V03.2), Georgian-language D00–D13 and DV reports, original test packages, final benchmark data, environment description and checksums.

**Publication status:** this branch currently contains the research index only. The experiment archives, documentation and primary data have not yet been uploaded.

Evidence must distinguish reference models from the original C implementation, structural estimates from measured executable sizes, repeated regression cases from unique cases, and QEMU target execution from physical hardware testing. No universal size or performance advantage is claimed.
